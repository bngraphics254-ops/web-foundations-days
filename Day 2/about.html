About QuickNotes

QuickNotes is a lightweight note-taking app built for speed. It keeps your notes short, searchable, and available on any device, so you can capture a thought before it slips away.

How to use QuickNotes

  1. Create a new note and give it a short, descriptive title.
  2. Type your content in the editor and add tags to group related notes.
  3. Save the note, then use search or tags to find it again later.
  4. Pin important notes to the top of your list for quick access.

Features

  • Fast, distraction-free note editor
  • Tags and folders for organisation
  • Full-text search across every note
  • Keyboard shortcuts for common actions
  • Works offline and syncs when you reconnect

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + F Search all notes
